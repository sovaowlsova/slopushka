# Slopushka
Slopushka is a fun little project I did for personal use. This is an AI bot for Discord. If you want to interact with the bot you can add it via the following link: https://discord.com/oauth2/authorize?client_id=1531797427894354063 The project is currently hosted on wispbyte
## 🎯 Features
* ✅ Gemini AI
* ✅ Dialog history is saved per server or pm
* ✅ System prompt
* ✅ Users can set a custom role for the bot or choose a ready one
* ✅ Users can change AI settings, including: temperature, top_p, thinking level
* ✅ Search command is implemented but unfortunately doesn't work due to the fact that Google search tool is a paid API option
* ✅ All API keys are safely stored in the .env file
## 🛠️ Tech stack
* Python
* Google AI studio
* Discord py
